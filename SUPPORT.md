## 🐛 Found a Bug?

If you've found a bug, please:

1. **Search existing issues** to see if it's already reported
2. **Check the troubleshooting guide** for known issues
3. **Create a bug report** with:
   - Clear description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable
   - Environment details (OS, browser, Node version)

[Create Bug Report](https://github.com/your-org/expense-tracker/issues/new?template=bug_report.md)

## 💡 Feature Request?

Have an idea for a new feature?

1. **Check the roadmap** to see if it's already planned
2. **Search existing issues** to avoid duplicates
3. **Create a feature request** with:
   - Problem statement
   - Proposed solution
   - Use cases
   - Priority level

[Create Feature Request](https://github.com/your-org/expense-tracker/issues/new?template=feature_request.md)

## 🔒 Security Issue?

**Do not report security vulnerabilities through public GitHub issues.**

Please email security concerns to: **security@your-domain.com**

See our [Security Policy](docs/SECURITY.md) for details.
